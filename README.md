#  Palindrome Checker

A simple web application that checks whether the entered word is a **palindrome** or not.

## Features

* Checks whether a word is a palindrome
* Simple and user-friendly interface
* Instant result display
* Case-insensitive checking

##  Technologies Used

* HTML5
* CSS3
* JavaScript

##  Project Structure

```text
Palindrome-Checker/
│
├── index.html
└── README.md
```

##  How It Works

1. Enter a word in the input box.
2. Click the **Check** button.
3. The application reverses the entered word.
4. It compares the original word with the reversed word.
5. The result is displayed on the screen.

##  Example

```text
Input: madam
Output: It is a Palindrome ✅
```

```text
Input: hello
Output: It is not a Palindrome ❌
```
